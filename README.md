## 🧰 Lingkungan Pengembangan

Semua tugas menggunakan stack yang sama:

- **Flutter SDK** 3.x + **Dart 3**
- **Material Design** (Material 3 pada tugas terbaru)
- **Firebase** (Firestore) untuk tugas yang membutuhkan backend
- Target platform: Android, iOS, Web, Windows, macOS, Linux

Cara menjalankan setiap tugas (dari folder repositori masing-masing):

```bash
flutter pub get
flutter run
```
